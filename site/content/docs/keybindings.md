## Navigation

| Key | Action |
| ---------- | ---------------- |
| j / Down | Move down |
| k / Up | Move up |
| gg | Jump to top |
| G | Jump to bottom |
| PgUp/PgDn | Scroll output |

## Actions

| Key | Action |
| ---------- | ---------------- |
| Enter | Expand/collapse |
| Tab | Switch view |
| e | Toggle errors |
| / | Search |
| q / Ctrl+C | Quit |

## Vim-style

tgdash uses vim-style keybindings throughout. If you
are comfortable with vim, you already know how to
navigate tgdash.

The `gg` binding requires pressing `g` twice in quick
succession, just like in vim.
